# Third-party notices

MetaForge is built on the software and the assets listed here. Each is used under its own licence, and this file is the notice those licences ask for.

> This file is generated by `npm run licences:notices` from `composer.lock`, `package-lock.json`, the installed packages and `scripts/licence-policy.json`. Do not edit it by hand; CI fails when it is out of date. See [docs/licences.md](docs/licences.md).

The PHP packages are the 96 that `composer install --no-dev` installs. The JavaScript packages are the 295 that the front end is built from (`dependencies` in `package.json` and what they need). Tools that only build or test the project are not shipped and are not listed.

## Packages that ask for more than a notice

These are under a licence that the project allows only by a written exception (`exceptions` in `scripts/licence-policy.json`).

- **dompdf/dompdf** (LGPL-2.1): Laravel Cashier draws the PDF of a billing invoice with it (`DompdfInvoiceRenderer`, the default `cashier.invoices.renderer`), for `settings.billing.invoices.download`. It is used as installed from Packagist, unmodified, so the LGPL asks for what this file and the package's own licence text already give: the notice, the licence text, and a copy you can replace (`composer update dompdf/dompdf` or another `InvoiceRenderer`).
- **dompdf/php-font-lib** (LGPL-2.1-or-later): Required by dompdf/dompdf (above), with the same use and the same duties.
- **dompdf/php-svg-lib** (LGPL-3.0-or-later): Required by dompdf/dompdf (above), with the same use and the same duties.
- **elkjs** (EPL-2.0): A dependency of @unovis/ts (graph layouts). Nothing in the built front end imports it (looked for in public/build on 2026-11-01, and `npm run build` is the place to look again if a chart type that lays out a graph is added), and it is unmodified. The Eclipse Public License asks that the source of what is distributed stays available, which the unmodified package on npm is.
